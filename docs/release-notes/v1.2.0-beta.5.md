## Feedback from beta.4

### Auto Clicker
- **Tap a marker to set that target.** A small window opens with the target's own settings: action, its duration, the wait after it, repeat count, and marker size. Each target can now have its own size.
- **⚙ is lighter.** It keeps what concerns the whole macro: which saved macro, mode (one after another / all at once), interval, start delay, and when to stop (manual, after N cycles, after a duration). Appearance stays in the app's *Look* tab.
- **－ on the panel** removes the last target; the target window also has a *Remove* button.

### Rally Timer
- The guide no longer tells leaders to subtract their rally time. It now reminds that every rally leader must pick **the same rally time** in the game (usually 5 min), and check it before each Deploy.

### Look and feel
- **App icon in black and white.** The logo on the home screen is animated in the accent colour you picked.
- **Smoother**: module transitions only animate position and opacity, and the costly blur behind cards is gone.
- **Easier to read**: brighter secondary text and borders, opaque cards, no tiny labels.
