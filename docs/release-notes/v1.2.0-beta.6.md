## Text Art, backup, and a lot of polish

### New: Text Art *(new, in test)*
- **Save your chat art and message templates**, sort them into folders, search them, and copy one in a tap, **exactly as saved** (spaces, indentation and line breaks included).
- **In-game preview.** The text is laid out like the game's chat bubble (16 emoji per line, a font close to the game's), so you can check it before pasting. A full-screen viewer shows one template at a time: **swipe left or right** to go through the list.
- **Comes with about 40 ready-made templates** in two folders, *Pixel Art* and *ASCII*.

### New: Backup and restore
- *Settings → Export a backup* saves your settings, module order, Text Art templates, Auto Clicker macros and Rally Timer data to **one file** (or text). There is no server: the file stays yours. *Import a backup* restores it, after showing what it contains.
- **Optional password**: the file is then encrypted (AES-256-GCM). A forgotten password cannot be recovered.

### Press and hold, everywhere
- **Press and hold an item for its menu**: edit, rename, duplicate, move, copy, delete. Deleting always asks first.
- **Auto Clicker**: a held macro can be edited, renamed, duplicated, copied as text or deleted without opening the Edit tab; a held target can be duplicated, moved or removed.
- **Text Art**: a held template or folder can be renamed, moved to a folder or deleted; folders can be reordered.

### Home screen
- **Reorder the modules.** Press and hold a tile, then drag it (or tap a tile, then its new place). The order is saved.
- **BETA TEST** tags with a light running around them and a breathing border for the modules still in test; a **NEW** tag with its own animation.
- No more scrollbar on the side, no bounce at the ends.

### Frakinator
- **Bear Trap only**, and now said so: a *How it works* button explains it (only attack and lethality count; hero skills are not taken into account; take the stats from a Terror rally's battle report). Based on the work of Frak: [frakinator.streamlit.app](https://frakinator.streamlit.app) · [Frak's Discord](https://discord.gg/QNGxu9nkp).
- A compact layout: one row per troop with narrow fields, so the whole form fits on screen.

### New defaults for everyone
- Pink accent colour, a new order of the home tiles, smaller Auto Clicker markers with a see-through panel that hides its markers while running, and a *Terror* macro whose steps are named.
- Existing installs keep their own settings and data.

### Changed
- **English and French only.** The other languages are archived in the repository and can be brought back later. If you had picked another language, the app starts in English.
- Auto Clicker: fixed a layout overflow in French on narrow screens.

### Install
- **Signing key changed.** This build is signed with the app's own release key; the previous betas were signed with a test key. **Uninstall the previous beta first**, and note that uninstalling erases its data (macros, templates): older versions have no export, so copy a macro as text from *Auto Clicker → Share* first if you want to keep one. From this version on, updates install over the previous one.
- Download the APK below, open it on your phone and allow installation from this source.
